# BMS

This repository contains the Building Management System.

Local credentials, data exports, and helper scripts are excluded from version control.
Set `SUPER_ADMIN_PASSWORD` before running `npm run seed:super-admin` in `BMS/`.
Optional test users are created only when `SEED_TEST_PASSWORD` is set.

| Area | Path |
| --- | --- |
| Backend API | `BMS/` |
| Frontend app | `BMS-frontend/bms-frontend/` |
| Developer documentation | `docs/` |
